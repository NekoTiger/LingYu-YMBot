# Quest 视频传输

在 Quest 3 浏览器中把录制的视频直接传到这台电脑。文件保存在 `uploads` 文件夹。

## 使用

1. 双击 `启动Quest视频传输.cmd`。
2. 电脑浏览器会自动打开传输页。页面右侧显示二维码和局域网地址。
3. 让 Quest 3 与电脑连接同一个 Wi-Fi，用头显浏览器扫描二维码。
4. 点“选择视频”，可一次选择多个文件。

传输按 8 MB 分片，网络短暂中断会自动重试。若页面刷新或浏览器关闭，重新选择同一个文件即可从已传输的位置继续。

## 注意

- 页面使用一次性生成并保存在 `.access-token` 的访问码，局域网内其他设备需要完整链接才能进入。
- 如果 Quest 3 打不开页面，先确认两台设备在同一 Wi-Fi；Windows 防火墙弹出提示时，允许 Python 访问“专用网络”。
- Web 页面受头显浏览器权限限制。如果文件选择器里看不到录像，可先用头显的“文件”应用把视频复制到“下载”再选择；仍不可见时，需要使用 USB 或 Meta Quest Developer Hub 导出。
- 二维码由本机已有的 `qrcode` Python 包生成。没有安装时页面仍可正常上传，只是不显示二维码。
- 停止传输：关闭启动窗口，或在窗口中按 `Ctrl+C`。
