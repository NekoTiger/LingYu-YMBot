# 学校通知与本轮答辩证据

依据 [2026 年培育项目中期检查及 2027 年项目认定通知](http://www.cxcy.ecnu.edu.cn/e6/99/c18349a779929/page.htm) 和项目文件夹内的中期评分表整理。公开通知原始网页已保存为同目录的 `school_notice.html`。

这次中期检查直接进行 2027 年国创、市创、校创分流。学院专家组在答辩后按学校分配名额集体评判，并非达到某个统一分数就自动获得国创。立项排名是已有基础，中期仍需证明当前进展与继续研究的能力。

- 项目负责人在学校教育教学管理平台提交中期材料，指导教师审核后才能流转到管理端。
- 学院汇总审核截止为 **2026 年 11 月 23 日 16:00**。具体学生提交与答辩时间以学院要求为准。
- 项目变更申请截止为 **11 月 20 日 16:00**；本轮没有修改项目名称、成员或导师。
- 中期分流阶段不能申请延期。国创资助标准为每项 2 万元，认定仍由学院评审决定。

## 评分表对应的材料

| 评分关注点 | 可展示的具体证据 |
|---|---|
| 项目总体与进展介绍 | 申报书需求到双臂、底盘协调、记录模块的对应表 |
| 科研训练过程完整 | 开源选择依据、模型问题、实验协议、失败案例和局限 |
| 任务完成与创新程度 | 原模型仿真适配、真实接触搬运、控制方法对照；定位为集成与实验验证 |
| 研究成果 | 可运行程序、两种任务视频、对照视频、统计图与原始日志 |
| 数据准确与文档规范 | 固定种子、全部失败记录、版本锁定、独立成功判据、源码哈希 |
| 进一步研究潜质 | 真实 VR 示教、可达性辅助底盘、碰撞约束、真机迁移的具体计划 |

## 答辩时可以准确表述的内容

“我们把项目已有机器人模型接入了 MuJoCo，基于开源 Mink 实现双臂和躯干的受限逆运动学，在接触动力学场景完成了单臂取物搬运与双臂托盘搬运。实验发现，仅降低每只手的世界位置误差仍可能造成共同夹持失稳。加入双臂相对位姿约束后，我们固定参数，用新种子比较三种方法，保留全部原始轨迹和失败案例。当前输入使用合成目标回放，VR 设备连接和真机实验是下一阶段任务。”

不能把合成目标回放说成已经采集真人 VR 数据，也不能把调用开源 IK 说成独立发明了全身控制算法。尚未发生的用户研究、真机实验、论文投稿、专利和经费支出，不应填入已完成成果。

申报书原计划在 8—10 月完成核心算法与仿真。实际材料应如实说明此前进展滞后、本轮集中补齐了哪些可验收内容，再用演示和数据说明后续研究能够继续推进。这里没有代填历史工作记录或团队分工完成情况。
